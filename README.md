# CodeAlpha AI Internship | AI Pipeline Portfolio 

Welcome to my internship repository for **CodeAlpha**. During this program, I developed four distinct AI pipelines, exploring different facets of Machine Learning, Deep Learning, and Computer Vision.

### [AI Language Translation Tool](https://github.com/Alihcyv/CodeAlpha_AI_internship/tree/main/ai-translation-tool)
**Goal:** To create a seamless translation experience between diverse languages.

### [FAQ Chatbot](https://github.com/Alihcyv/CodeAlpha_AI_internship/tree/main/Hybrid-FAQ-chatbot)
**Goal:** To automate customer support by providing instant answers to common queries.

### [LSTM Music Generation](https://github.com/Alihcyv/CodeAlpha_AI_internship/tree/main/Music-Generation-LSTM)
**Goal:** To generate original MIDI music compositions based on classical patterns.

### [Real-Time Object Detection](https://github.com/Alihcyv/CodeAlpha_AI_internship/tree/main/RealTime-Object-Detection)
**Goal:** To identify and localize multiple objects within a live video stream.

## Tech Stack
- **Languages:** Python
- **Deep Learning:** TensorFlow, Keras
- **Libraries:** NumPy, Pandas, Matplotlib, OpenCV, Music21, NLTK
- **Tools:** Jupyter Notebook, Git
