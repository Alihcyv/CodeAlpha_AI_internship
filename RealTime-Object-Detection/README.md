# Real-Time Object Detection and Tracking 

This project implements a real-time object detection and tracking system using the YOLOv8 model and the BoT-SORT algorithm. It can process video streams from a webcam or a video file, detecting objects and assigning them unique tracking IDs.

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Alihcyv/RealTime-Object-Detection-Tracking.git
cd RealTime-Object-Detection-Tracking
```
### 2. Install dependencies
```bash
pip install -r requirements.txt
```
### 3. Run the application
```bash
python app.py
```
